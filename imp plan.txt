============================================================
1. PROJECT OBJECTIVE
============================================================

ClarifiBids is an intelligent assistance layer over the existing GePNIC eProcurement portal.

The system must NOT modify or replace GePNIC's core procurement workflow or transaction processing.

ClarifiBids should help users understand GePNIC-related information through:

- context-aware query understanding
- query categorisation
- user-role awareness
- intent recognition
- required-context/evidence identification
- knowledge retrieval
- baseline Vector RAG
- Graph RAG for procedural/context-dependent/multi-hop queries
- evidence relevance evaluation
- evidence sufficiency evaluation
- corrective retrieval
- evidence-grounded response generation
- source attribution
- evaluation and benchmarking

The system should be designed as a research prototype that can progressively evolve from an FAQ-only MVP into the full dissertation architecture.
